# Dynamic Price Optimization & Revenue Intelligence System

## 📌 Overview

This project aims to develop an AI-powered Dynamic Price Optimization and Revenue Intelligence platform that helps businesses optimize product pricing using machine learning, market trends, demand forecasting, competitor analysis, and historical sales data.

## 🚀 Tech Stack

### Frontend
- React.js
- Vite

### Backend
- Python
- FastAPI

### Database
- PostgreSQL

### AI/ML
- Scikit-learn
- XGBoost
- Pandas
- NumPy
